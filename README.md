# 白色失明文字麻将

> 汉字组词造句 · 人机混战 · WebRTC 联机 · 单文件 HTML 游戏

一款基于汉字组词玩法的四人麻将游戏。手牌由汉字组成，通过吃牌、组词造句来胡牌。支持真人联机和人机混战，单文件即可运行，无需后端。

## ✨ 功能特性

- **🀄 汉字麻将**：192 张牌（182 个不同汉字，其中 10 个字各 2 张），词库 825 条词语短句
- **🤖 人机混战**：不足 4 人自动补 AI，最少 1 人即可开始，AI 纯随机出牌
- **🌐 双模式联机**：默认走声网 RTM 公共中继通道（跨网络稳定，手机也能联机）；也支持自建 WebSocket 信令服务器 + WebRTC P2P（自定义地址 + ngrok）
- **📱 手机适配**：大厅竖屏 + 对局横屏自动切换，自动全屏并锁定横屏，竖屏进入弹出旋转提示
- **🔄 掉线重连**：刷新页面自动恢复对局，房主退出自动迁移（座位号最小的真人接管）
- **🎯 双胡牌标准**：真人投票胡 / AI 词库回溯胡
- **🔗 分享链接**：一键复制房间信息，房客打开自动识别并填入信令地址 + 房间号
- **🖱️ 手牌拖拽**：自由整理手牌顺序（仅影响显示）
- **💬 房间聊天**：内置聊天面板，默认收起可展开
- **📖 规则弹窗**：大厅和对局内均可随时查看玩法规则

## 🎮 游戏规则

### 基本流程
1. 每名玩家起手 13 张牌，庄家首轮直接摸牌
2. 摸牌 → 出牌 → 下家选择吃/胡/过
3. 吃牌后跳过摸牌，直接出牌
4. 直到有人胡牌或牌库摸空（流局）

### 吃牌
- 只能吃**上家**打出的牌，用手牌 + 打出的字组成词库中的词语（2-4 字）
- 吃牌后跳过摸牌，直接出牌
- **无碰牌**：原版牌库同字最多 2 张，无法凑齐 3 张

### 胡牌条件
- **真人胡牌**：点击「胡」发起投票，其他真人全票同意即胡（不校验手牌）
- **AI 胡牌**：系统自动校验 14 张能否全部拆分成词库中的词语或短句
- AI 不参与投票，仅真人之间互相投票

### 人机混战
- 不足 4 人时由 AI 自动补位，最少 1 名真人即可开始
- AI 纯随机出牌，摸到能胡的牌自动申请胡牌
- AI 有 30% 概率吃牌
- AI 胡牌走词库回溯校验，不需要真人投票

## 🌐 联机部署

支持两种联机方式，玩家可根据情况选择：

### 方式一：声网 RTM 公共通道（默认，推荐）

**信令服务器地址留空**即使用声网 RTM 公共中继通道。游戏数据通过声网全球节点中继广播，不受 NAT 打洞限制，手机跨网络（4G/5G/WiFi）也能稳定联机。已内置配置，开箱即用，无需额外部署后端。

> 说明：声网 RTM 免费额度为每月 100 万条消息，个人娱乐完全够用。

### 方式二：自建信令服务器（可选）

在「信令服务器地址」框填入自建服务器地址（房主需先启动服务器并用 ngrok 暴露公网），游戏数据走浏览器间 WebRTC P2P 直连。适合对隐私有更高要求或想完全自主掌控的场景。

项目提供 Python 和 Node.js 两个版本：

```bash
# Python 版（纯标准库实现，无需安装依赖）
python signaling-server.py

# Node.js 版
npm install ws
node signaling-server.js
```

默认监听 `ws://0.0.0.0:8765`，用 ngrok 映射到公网：

```bash
ngrok http 8765
```

将 ngrok 给出的 `https://xxx.ngrok-free.app` 改成 `wss://xxx.ngrok-free.app`，填入游戏大厅的「信令服务器地址」框，所有玩家填同一个地址即可联机。

> 注意：WebRTC P2P 在部分运营商网络（如移动 4G）下可能打洞失败，导致无法联机。如遇此问题请切换到方式一声网公共通道。

### 分享链接

- 房主点击「分享链接」即可复制包含信令地址 + 房间号的文本
- 房客打开游戏网址后会自动读取剪贴板，识别并填入信令地址 + 房间号

### GitHub Pages 部署

1. 将本仓库上传到 GitHub
2. Settings → Pages → Source 选 `Deploy from a branch`，Branch 选 `main` / `(root)`
3. 等待 1-2 分钟即可获得访问地址

## 🛠️ 技术栈

- **前端**：纯 HTML + CSS + 原生 JavaScript，无框架
- **公共联机**：声网 Agora RTM（中继广播，跨网络稳定），已内置配置开箱即用
- **自建联机**：WebRTC (RTCPeerConnection) + WebSocket 信令
- **构建**：无构建工具，单文件直接运行
- **存储**：localStorage 保存对局状态用于重连

## 📝 注意事项

- 默认使用声网 RTM 公共通道联机，已内置配置，开箱即用
- 自建信令模式下，部分运营商网络（如移动 4G）可能 WebRTC 打洞失败，建议切换声网公共通道
- STUN 保留 3 个（2 个 Google + 1 个第三方），用于自建信令模式下的 NAT 穿透
- iOS Safari 对横屏锁定 API 支持有限，可能需手动旋转手机
- 部分公司/学校网络会屏蔽 WebRTC，可切换手机热点测试
- 对局状态保存在 localStorage（key 为 `mahjong_save_房间号`），重进同房间可恢复
- 牌库和词库可在 `index.html` 的 `CARD_CHARS` 和 `HU_WORDS` 变量中自定义
